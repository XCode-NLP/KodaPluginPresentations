# Презентации для Koda Desktop

Установите `dev.koda.presentations-0.2.0.kodaplugin` в **Маркетплейс → Установленные** и откройте панель «Презентации» в чате проекта. Создайте документ, откройте существующий или укажите путь к PPTX относительно папки проекта.

Щелчок выделяет объект. Shift + щелчок добавляет объект к выделению. Перетаскивайте выделение или маркер в нижнем углу, чтобы изменить положение и размер. Двойной щелчок по тексту включает редактирование. Кнопка «Обсудить в чате» вставляет ссылку на слайд и выделение. Для завершения правки текста щёлкните за пределами текста, для отмены нажмите Esc.

## Хранение и совместимость

- Документы находятся в `presentations/<id>/`. Метаданные и версии находятся в `document.json`, данные слайдов в `slides/`, PNG-ресурсы в `resources/`. Отмена и повтор хранят до 50 действий в пределах бюджета документа и истории.
- PPTX импортируется локально, оригинал сохраняется. Простой текст и фигуры остаются редактируемыми. Группы, таблицы и диаграммы преобразуются в изображения, когда доступна статическая отрисовка. Отчёт показывает упрощения и места, где понадобились заглушки. Размер PPTX до 12 МиБ, до 100 слайдов.
- PPTX и растровый PDF сохраняются в `presentations/<id>/exports/`. Кнопка открывает папку проекта, поскольку SDK предоставляет открытие только зарегистрированного корня. Путь к конкретному файлу показан в панели.
- Данные проходят через SDK частями. Фиксированный обработчик из пакета запускается в собственной служебной папке плагина. Обработчик пишет только в `presentations/` и служебную папку. Для каждого запуска действует стандартный лимит SDK в 10 секунд.

## Дизайн-система для агента

Агент строит слайды не координатами, а через дизайн-систему из `src/design/`:

- `get_design_system` отдаёт гайд (порядок работы, правила текста и визуала), каталог тем и каталог макетов со слотами.
- Темы (`themes.ts`) хранят токены: 13 цветовых ролей, шрифты заголовка и текста, шкалу кеглей. Объекты запоминают роль (`accent`, `h2`, `heading`), поэтому `set_presentation_theme` перекрашивает всю колоду. У старых документов роли выводятся из текущих цветов при первой смене темы. Акцент каждой темы проходит контраст WCAG 4.5:1 на фоне и подложке.
- `add_layout_slide` собирает слайд из 20 макетов (`layouts.ts`) по сетке 960×540 с полями 64/48 и подгоняет кегль под рамку. `replaceSlideId` пересобирает существующий слайд, `notes` пишет заметки докладчика, они уходят в PPTX.
- `check_presentation` (`lint.ts`) ищет переполнение текста, наложения, низкий контраст, выход за поля, почти совпадающие края, мелкий кегль, перегруз словами, цветами и размерами, оставленные заглушки и повтор макета три раза подряд. Те же проверки возвращаются после каждого `apply_presentation_operations` и `add_layout_slide` для затронутых слайдов.
- `render_slides` просит открытую панель отрисовать до 8 слайдов в `presentations/<id>/previews/<slide>.png`; агент смотрит их своим инструментом чтения файлов. Без открытой панели инструмент через 5 секунд сообщает об этом.

## Сборка и проверка

Плагин написан на TypeScript. Из корня репозитория:

```sh
npm ci
npm run typecheck
npm test
npm run pack
```

Архив появится в `dist/`.

Для проверки в Electron выполните `npm run test:presentations:smoke` из Koda Desktop. Для другого расположения плагина передайте путь после `--`.

## Выпуск в каталог

Используйте Node.js 22.12 или новее. Тег `v<версия>` должен совпадать с версией в `koda-plugin.json`. Workflow `release.yml` проверит проект и приложит к GitHub Release архив и `SHA256SUMS`. Для записи в каталоге возьмите URL и SHA-256 из этого релиза. Формат записи описан в [KodaPlugins](https://github.com/XCode-NLP/KodaPlugins#формат-записи).
